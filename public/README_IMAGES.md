# Instructions pour télécharger les images avant/après

## Sources recommandées :

### 1. Unsplash (Meilleure qualité)
- **Salons avant/après** : https://unsplash.com/s/photos/living-room
- **Home staging** : https://unsplash.com/s/photos/home-staging
- **Avant/Après** : https://unsplash.com/s/photos/before-after

### 2. Pexels (Alternative)
- **Salons** : https://www.pexels.com/search/living%20room/
- **Avant/Après** : https://www.pexels.com/search/before%20after/

## Comment télécharger :

1. **Choisir 2 images** (une avant, une après)
2. **Cliquer sur "Télécharger gratuit"** 
3. **Renommer** en `avant.jpg` et `apres.jpg`
4. **Placer** dans le dossier `public/`

## Images idéales pour home staging :

### AVANT (pièce à transformer) :
- Salon un peu encombré
- Lumière moyenne  
- Déco personnelle
- Aspect "vécu"

### APRÈS (pièce transformée) :
- Salon épuré et rangé
- Lumière chaude et abondante
- Couleurs neutres (blanc, gris, beige)
- Quelques accessoires décoratifs

## Une fois téléchargées :
Les images apparaîtront automatiquement sur votre site dans la section "Avant / Après" !
